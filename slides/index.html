Seguridad & Desacoplamiento

Arquitectura: Más Allá de un fetch()

El error común en desarrollo web vs el patrón de arquitectura enterprise

❌

Anti-Patrón: Llamada Directa

  • API Keys expuestas: Visibles en DevTools y bundle cliente.
  • Cero control de costos: Sin rate limiting ni cuotas.
  • Prompt Injection: Lógica de sistema manipulable.
  • Fuerte Acoplamiento: Dependencia directa al vendor.
🛡️

Solución: Patrón BFF en Node.js

  • Zero-Leak: Secretos protegidos en variables de entorno.
  • Control de Tráfico: Rate limiting, caché y validación.
  • Streaming Eficiente: Retransmisión token a token vía SSE.
  • Vendor Agnostic: Libertad de alternar modelos LLM.
[Minuto 4-5.5] El rol del arquitecto es garantizar seguridad y gobernanza. Conectar el browser directo al LLM es negligente. El BFF actúa como aduana, orquestador y optimizador de costos.

Performance & UX Engineering

La Importancia del Streaming (TTFT)

Time To First Token (TTFT): La métrica de oro en arquitecturas cognitivas

Request / Response Tradicional ~6000ms
  • Usuario espera inmóvil frente a un spinner vacío.
  • Alto riesgo de timeout y abandono de sesión.
  • Percepción de lentitud extrema.
Streaming con Server-Sent Events ~300ms ⚡
  • Primeros tokens aparecen casi de inmediato.
  • SSE: Estándar HTTP ligero, sin sobrecarga de sockets.
  • Pasa transparente por proxies, CDNs y firewalls.
[Minuto 7-10] En sistemas con LLMs, la latencia de inferencia completa puede rondar 5 a 10 segundos. Si envías un JSON estático, la UX es pésima. Si usas SSE, el usuario lee al instante a los 300ms.
Implementación Backend

Streaming con Express & TypeScript

Control de cabeceras HTTP, flujo asíncrono y delimitador SSE estándar

server/index.ts
TypeScript 

// 1. Headers obligatorios para Server-Sent Events (SSE)
res.setHeader('Content-Type', 'text/event-stream');
res.setHeader('Cache-Control', 'no-cache, no-transform');
res.setHeader('Connection', 'keep-alive');

// 2. Iteramos sobre los chunks asíncronos del modelo
for await (const chunk of aiStream) {
  const payload = JSON.stringify({ text: chunk.text });
  res.write(`data: ${payload}\n\n`); // Protocolo SSE: data: \n\n
}

// 3. Señal de finalización limpia
res.write('data: [DONE]\n\n');
res.end();
[Minuto 10-12] Observen la simplicidad arquitectónica: 3 headers estándar, el bucle for await que no satura memoria, y el protocolo de eventos data: terminando con [DONE].
Implementación Frontend

Consumiendo Web Streams Nativos

Cero dependencias pesadas: lectura nativa con ReadableStream y TextDecoder

public/app.js
Web Streams API 

const response = await fetch('/api/chat', { method: 'POST', body });
const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  
  const chunk = decoder.decode(value, { stream: true });
  renderTokenInUI(chunk); // Renderizado progresivo sin bloquear el hilo principal
}
[Minuto 12-14] Cero librerías externas de 500kb en el cliente. El browser moderno lee flujos binarios con getReader() y TextDecoder nativos.
